# Product direction for Claude

Use this file as the owner's product vision when planning or implementing a related request. It is a direction and backlog, not a request to implement every item at once. Follow the scope of the current task; inspect the game and relevant project docs before proposing or making changes.

## Core goals

### Make element choice matter

Keep the controls and overall combat framework learnable across all four elements, but make each element a genuinely different playstyle. A choice should change how the player approaches fights, not just the colors, effects, or damage numbers. Preserve a clear identity for every element in its attacks, strengths, weaknesses, and combat rhythm.

### Give enemies distinct identities

Revamp the enemy roster so each enemy is recognizable and creates a different combat problem. Differentiate them through readable silhouettes, behavior, attack patterns, and battlefield roles - not only health or damage values. Make their tells fair and understandable.

### Make progression exciting

Improve the skill trees so upgrades build toward powerful, understandable outcomes. Favor new mechanics, meaningful choices, and synergies that change how a character plays over a sequence of minor stat increases. Research _Marvel's Spider-Man 2_ skill trees for high-level progression and presentation principles if useful, but create original mechanics, names, and content.

### Raise the audio quality

Create a cohesive, memorable sound design and soundtrack that suit the game's world and make combat feel impactful. Avoid generic, repetitive, or arbitrary "AI-slop" sounding results. Every sound should have a clear purpose and fit the action; prioritize quality and cohesion over quantity.

Audio may be composed or synthesized, or sourced from the web when an asset is genuinely suitable. For any sourced asset, confirm that its license permits the intended use and retain required attribution. Do not add assets merely because they are available.

## Optional tools

- Use Blender when it materially helps create or improve a model, animation, or asset pipeline; it is optional, not a requirement.
- Use web-sourced audio only when it is an excellent fit and its licensing and attribution requirements are clear.

## Implementation guidance

- These are ongoing goals. Work on only the part requested or directly needed for the current task; do not treat the list as authorization for a broad rewrite.
- Before changing a system, inspect its current implementation and preserve existing behavior outside the agreed scope.
- Keep designs readable, satisfying, and feasible for the browser game, touch controls, and mobile performance budget.
- For design research, extract general principles and apply them to original game content rather than copying another game's protected expression.
